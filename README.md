# Chiang Mai Self-Reliance Land Search Plan (แผนหาที่ดินเชียงใหม่ วิถีพึ่งตนเอง)

Bilingual (English + ภาษาไทย) interactive guide and checklist for finding and buying self-reliant homestead land within ~1 hour of Chiang Mai city, inspired by **Jon Jandai & Pun Pun Center for Self-Reliance (บ้านพันพรรณ อ.แม่แตง)**.

## 🌐 Live GitHub Pages Site
**[https://lxwxjx-oss.github.io/punpun/](https://lxwxjx-oss.github.io/punpun/)**

## What's Inside
1. **Language Toggle (`EN + ไทย` / `ภาษาไทย` / `English`)** for easy reading and sharing.
2. **Top 5 Target Districts Within ~1 Hour of Chiang Mai** (Mae Taeng, Doi Saket/Mae On, San Pa Tong/Mae Wang, Samoeng, Phrao) with direct Google Maps links.
3. **One-Click Thai Search Hub** with copyable Thai search phrases and direct links to Facebook Search, Google, Teedin108, and DOL LandsMaps.
4. **Interactive 4-Phase Action Plan & Checklist** (saves progress in browser storage).
5. **Title Deed Guide** (`Chanote` vs `Nor Sor 3 Gor` vs `Sor Por Gor 4-01`).
6. **Field Inspection Questionnaire** (Water, 2024 Flood History, Soil for Adobe Bricks, Public Road Frontage).
